# 오파 새 버전 자동 알림

자동 기록 연결이 켜져 있으면 폰 부팅 후 오파에 처음 연결될 때, 연결이 끊겼다가 다시 연결될 때 업데이트 메타데이터를 확인합니다. 연결 중에는 15분마다 GitHub 버전을 다시 확인하고, 설치 상태는 약 1분마다 확인합니다. 네트워크 실패는 최소 1분 뒤 재시도합니다. Android 절전/네트워크 제한이 있으면 확인이 늦어질 수 있습니다.

대상은 등록된 활성 기기와 일치하는 업데이트 연결 파일의 오파입니다. GitHub 채널은 기존 `benign07/openpilot`의 `hud-device-updates-20260928/updates/hud/latest.json`입니다. 임의 소스 커밋이 아니라, 이 채널에 게시한 릴리스의 순번을 실기기 설치 순번과 비교합니다. 메타데이터 확인으로 설치 예약·재부팅이 발생하지 않습니다.

새 버전을 찾으면 Android 알림과 HUD/운행모드 위젯의 별도 업데이트 표시를 제공합니다. 누르면 기존 변경점·업데이트 예약 화면이 열립니다. 기기·릴리스·파일 해시가 같은 알림은 한 번만 표시하며, 앱 재시작 후에도 중복 알림을 막습니다. 알림 권한이 없으면 위젯 표시는 유지되고, 이후 권한이 허용되면 다시 알림을 시도합니다. 설치 예약 중이거나 이미 설치된 버전은 표시하지 않습니다. 오프라인에서는 마지막으로 확인한 위젯 표시가 남을 수 있으며, 다시 연결하면 실제 상태를 갱신합니다.

설치는 사용자가 직접 예약해야 합니다. 기존 오파 서버가 P 정차·제어 해제, 서명·해시·기준 파일 및 재부팅 후 상태를 검증합니다. 휴대폰 앱 업데이트와 오파 릴리스는 별개입니다. SSH로만 설치 가능한 변경은 이 알림의 설치 가능한 릴리스로 표시하지 않습니다.

검증: 순번 비교, 누락/잘못된 메타데이터, 진행 중 설치 억제, 기기별 중복 방지 식별자, 부팅·재연결·주기·실패 재시도 정책에 대한 JVM 단위 테스트를 포함합니다. 자동 감시는 기존 기록 보관 작업과 별도 실행기로 동작하여 GitHub 응답이 기록 다운로드를 막지 않습니다.
